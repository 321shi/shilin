# 产品需求文档 (PRD)

## 1. 产品概述

**兼职工厂信息管理平台** - 一款高效的招聘信息管理工具，帮助用户快速解析、自动分类和导出兼职与工厂招聘信息。

**核心价值：**
- 节省手动整理信息的时间，提高工作效率
- 智能解析招聘文本，自动提取关键信息
- 分类清晰，查找便捷

**目标用户：**
- 招聘中介人员
- 人力资源专员
- 需要管理大量招聘信息的个人或团队

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|---------|
| 普通用户 | 直接使用所有功能 | 解析、添加、编辑、删除、导出 |

### 2.2 功能模块

1. **主页/仪表板**：兼职和工厂信息概览
2. **兼职管理**：兼职信息列表、添加、编辑、删除、导出
3. **工厂管理**：工厂信息列表、添加、编辑、删除、导出
4. **文本解析**：粘贴文本自动识别并提取信息

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主页 | 信息卡片 | 显示兼职和工厂总数统计 |
| 主页 | 快捷操作 | 快速跳转到对应模块 |
| 兼职管理 | 信息列表 | 展示所有兼职信息，支持排序 |
| 兼职管理 | 添加表单 | 手动添加或粘贴文本自动解析 |
| 兼职管理 | 导出功能 | 一键导出为Excel文件 |
| 工厂管理 | 信息列表 | 展示所有工厂信息，支持排序 |
| 工厂管理 | 添加表单 | 手动添加或粘贴文本自动解析 |
| 工厂管理 | 导出功能 | 一键导出为Excel文件 |

## 3. 核心流程

### 3.1 信息解析流程

```
用户粘贴文本 → 系统识别类型(兼职/工厂) → 自动提取关键信息 → 用户确认修改 → 保存
```

### 3.2 信息管理流程

```
查看列表 → 新增/编辑/删除 → 数据更新 → 导出Excel
```

### 3.3 排序流程

```
选择排序字段(日期/地点/薪资) → 选择排序方式(升序/降序) → 显示排序结果
```

## 4. 用户界面设计

### 4.1 设计风格

**风格定位：专业简洁、数据导向**

**配色方案：**
- 主色：深蓝色 `#1e3a5f` - 传达专业、可信赖
- 强调色：活力橙色 `#ff6b35` - 用于重要操作按钮
- 背景色：浅灰 `#f5f7fa` - 保持清爽
- 文字色：深灰 `#2d3748` - 高可读性

**字体选择：**
- 标题：思源黑体 (Noto Sans SC) Bold
- 正文：思源黑体 (Noto Sans SC) Regular

**布局风格：**
- 卡片式布局，每个招聘信息独立卡片
- 顶部导航栏，左侧标签切换（兼职/工厂）
- 表格视图和卡片视图切换

**图标风格：**
- 使用emoji增加视觉趣味性（💰、🏭等）

### 4.2 响应式设计

- 桌面优先设计
- 移动端自适应，保持核心功能可用
- 表格在移动端自动转换为卡片列表

## 5. 数据字段设计

### 5.1 兼职信息字段

| 字段 | 说明 | 示例 |
|------|------|------|
| id | 唯一标识 | 自动生成 |
| salary | 日薪 | 130 |
| location | 地点 | 国博 |
| date | 日期 | 15-17号 |
| time | 工作时间 | 8:30-17:30 |
| requirements | 身高/年龄要求 | 穿鞋160+35岁内 |
| clothing | 服装要求 | 短裙裤 |
| meals | 是否包餐 | 包中餐 |
| contact | 联系方式 | 名字电话身高体重生活照 |
| idRequired | 是否需要身份证 | 是 |
| deposit | 押金 | 压20取消不退 |
| notes | 备注 | 不满报名档期70%结 |
| createdAt | 创建时间 | 自动记录 |

### 5.2 工厂信息字段

| 字段 | 说明 | 示例 |
|------|------|------|
| id | 唯一标识 | 自动生成 |

| location | 地点 | 蔡甸永安服饰 |
| date | 面试/工作日期 | 15号-18期间 |
| interviewTime | 面试时间 | 9点-15点 |
| age | 年龄要求 | 18-48岁 |

| accommodation | 住宿 | 包住宿，水电费平摊 |
| deposit | 押金 | 住宿押金200元随走随退 |
| meals | 餐饮 | 园区有食堂 |
| insurance | 保险 | 保险100/月 |
| notes | 注意事项 | 禁止拖鞋、短裤、凉鞋 |
| createdAt | 创建时间 | 自动记录 |

## 6. Excel导出功能

### 6.1 导出格式

- 文件名格式：`兼职信息_YYYYMMDD_HHmmss.xlsx` / `工厂信息_YYYYMMDD_HHmmss.xlsx`
- 每个模块单独导出
- 包含表头和所有字段
- 中文表头便于阅读
