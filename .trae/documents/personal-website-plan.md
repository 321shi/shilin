# 个人网站开发计划

## 一、项目概述

### 1.1 项目目标
创建一个综合性个人网站，包含一个极具创意的台灯登录页面，以及炫酷的个人主页展示。整体设计风格为"现代炫酷 + 趣味交互"。

### 1.2 核心功能模块
1. **台灯登录页**：独特的拖拽交互式登录界面（整合用户提供的设计）
2. **个人主页**：动态粒子背景 + 玻璃态设计的综合性展示页面
   - 首页（Hero）：极具视觉冲击力的个人介绍
   - 关于我：个人背景与技能展示
   - 作品集：项目展示
   - 博客：文章预览
   - 联系方式：社交媒体链接

### 1.3 设计风格定义
**现代炫酷 + 趣味交互**：
- **登录页**：深色主题 + 台灯发光效果 + 拖拽交互 + 动态色彩变化
- **主页**：深色主题 + 动态粒子背景 + 玻璃态 UI + 流畅动画
- 共性：渐变发光效果、流畅动画、高对比度的视觉设计

## 二、技术架构

### 2.1 技术栈
- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式**：Tailwind CSS + 原生 CSS（登录页特殊样式）
- **图标库**：Lucide React
- **路由**：React Router DOM v7
- **动画**：GSAP（登录页）+ CSS 动画（主页）
- **粒子效果**：Canvas API

## 三、登录页设计（台灯交互）

### 3.1 核心交互机制
**用户提供的台灯设计核心要素**：
- 台灯 SVG 图形，带有可爱的表情
- 可拖拽的灯绳
- 拖动超过阈值（50px）触发"开灯"动画
- 开灯后登录表单淡入显示
- 动态色彩变化（HSL 色相随机变化）

### 3.2 动画系统
- **GSAP 动画库**：用于复杂的台灯拖拽和变形动画
- **MorphSVGPlugin**：灯绳形态变化
- **Draggable**：拖拽交互
- **音效**：点击音效反馈

### 3.3 视觉效果
- **深色背景**：`#121921`
- **发光效果**：根据台灯颜色动态变化
- **玻璃态表单**：`rgba(18, 25, 33, 0.9)` 背景
- **发光边框**：与台灯颜色同步的动态边框

### 3.4 表单设计
- 用户名/账号输入框
- 密码输入框
- 登录按钮（渐变背景）
- 忘记密码链接

## 四、个人主页设计

### 4.1 色彩系统
```css
/* 主色调 */
--primary: 线性渐变 #6366f1 → #8b5cf6（靛蓝到紫罗兰）
--secondary: #06b6d4（青色）
--accent: #f59e0b（琥珀色）

/* 深色主题 */
--background: #0f172a（深蓝黑）
--surface: rgba(30, 41, 59, 0.7)（半透明深蓝）
--text: #f1f5f9（浅灰白）
--muted: #94a3b8（柔和灰）

/* 发光效果 */
--glow-color: 动态渐变（与登录页呼应）
```

### 4.2 字体系统
- **标题字体**：Space Grotesk（科技感强）
- **正文字体**：Inter（清晰易读）
- **中文字体**：Noto Sans SC

### 4.3 粒子背景效果
- **粒子数量**：100-150 个
- **粒子大小**：2-6px 随机
- **运动**：缓慢漂浮 + 鼠标交互（涟漪效果）
- **颜色**：紫、青、蓝渐变色
- **连线**：距离较近的粒子之间连线

## 五、功能模块详细设计

### 5.1 台灯登录页（Login.tsx）

**视觉元素**：
- 全屏居中的台灯 SVG
- 拖拽区域（台灯绳）
- 玻璃态登录表单（初始隐藏）
- 签名：2026/3/30 Mr.L

**交互流程**：
1. 用户看到台灯（关灯状态）
2. 用户拖动灯绳
3. 拖动超过阈值，台灯"亮起" + 发光效果
4. 登录表单淡入，带发光边框
5. 用户输入账号密码登录
6. 成功后跳转到个人主页

**技术实现**：
- 使用 `useRef` 管理 GSAP 动画
- 使用 `useState` 管理登录状态
- 整合 GSAP、Draggable、MorphSVGPlugin
- 表单验证逻辑

### 5.2 Hero Section（首屏）

**视觉元素**：
- 全屏高度，居中对齐
- Canvas 粒子背景
- 头像（圆形，带发光边框）
- 主标题：姓名 + 职位标签
- 副标题：个人标语
- CTA 按钮："了解更多" + "联系我"

**动画效果**：
- 页面加载时元素依次淡入
- 头像悬浮动画
- 粒子随鼠标移动产生涟漪

### 5.3 About Section（关于我）

**内容**：
- 个人简介
- 技能标签云
- 教育/工作经历时间线

**布局**：双栏或单栏响应式布局

### 5.4 Projects Section（作品集）

**内容**：
- 4 个项目卡片
- 封面图、项目名称、描述、技术标签、链接

**布局**：2 列网格，玻璃态卡片

### 5.5 Blog Section（博客）

**内容**：
- 最新 4 篇文章预览
- 标题、摘要、日期、分类标签

### 5.6 Contact Section（联系方式）

**内容**：
- 社交媒体链接（GitHub, LinkedIn, Email）
- 联系邀请语

## 七、关键设计决策

### 7.1 整合用户提供的台灯设计
- 保持原始设计的完整交互体验
- 将 HTML/CSS/JS 代码适配为 React 组件
- 使用 useRef 管理 GSAP 实例
- 保持动态色彩变化效果

### 7.2 登录验证策略
- 使用 localStorage 模拟登录状态
- 硬编码测试账号（方便演示）
- 后续可扩展为真实后端 API

### 7.3 动画技术选择
- **GSAP**：复杂的时间线动画和拖拽交互
- **CSS**：简单的过渡和悬停效果
- **Canvas**：粒子背景效果

### 7.4 性能考虑
- 粒子数量可配置
- 使用 requestAnimationFrame
- 组件懒加载
- 图片优化
