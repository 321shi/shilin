# 个人网站开发计划

## 一、项目概述

### 1.1 项目目标
创建一个综合性个人网站，展示个人品牌形象、作品集、技能和博客文章。设计风格定位为"现代炫酷"，具有强烈的视觉冲击力和出色的用户体验。

### 1.2 核心功能模块
- **首页（Hero）**：极具视觉冲击力的个人介绍区
- **关于我**：个人背景、技能、经历的展示
- **作品集**：展示个人项目或作品
- **博客**：技术文章、生活随笔等内容
- **联系方式**：社交媒体链接、联系表单

### 1.3 设计风格定义
**现代炫酷风格**：
- 深色主题为主，搭配渐变色彩
- 动态粒子/几何背景动画
- 玻璃态（Glassmorphism）UI 设计
- 流畅的滚动动画和微交互
- 大胆的排版和留白
- 科技感的视觉效果

## 二、技术架构

### 2.1 技术栈
- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式**：Tailwind CSS
- **图标库**：Lucide React
- **路由**：React Router DOM v7
- **动画**：CSS 动画 + React Motion

### 2.2 项目结构

### 2.3 路由设计
单一页面应用，所有内容在一个页面内通过锚点导航展示：
- `/` - 首页（包含所有 section）
- 导航锚点：#hero, #about, #projects, #blog, #contact

## 三、页面设计规范

### 3.1 色彩系统
```css
--primary: 线性渐变 #6366f1 → #8b5cf6（靛蓝到紫罗兰）
--secondary: #06b6d4（青色）
--accent: #f59e0b（琥珀色）
--background: #0f172a（深蓝黑）
--surface: rgba(30, 41, 59, 0.7)（半透明深蓝）
--text: #f1f5f9（浅灰白）
--muted: #94a3b8（柔和灰）
```

### 3.2 字体系统
- **标题字体**：Space Grotesk（科技感强）
- **正文字体**：Inter（清晰易读）
- **中文字体**：Noto Sans SC

### 3.3 组件设计
#### 3.3.1 玻璃态卡片
- 背景：`rgba(30, 41, 59, 0.7)`
- 边框：`1px solid rgba(255, 255, 255, 0.1)`
- 模糊：`backdrop-blur-xl`
- 圆角：`16px`
- 阴影：`0 8px 32px rgba(0, 0, 0, 0.3)`

#### 3.3.2 渐变按钮
- 背景：线性渐变 primary
- 悬停：增强发光效果
- 圆角：`12px`
- 内边距：`12px 24px`

#### 3.3.3 文字排版
- 标题：`text-4xl` 到 `text-7xl`，字重 700
- 副标题：`text-xl` 到 `text-2xl`，字重 600
- 正文：`text-base`，字重 400
- 字间距：标题 `tracking-tight`

## 四、功能模块详细设计

### 4.1 Hero Section（首屏）
**视觉元素**：
- 全屏高度，居中对齐
- 动态粒子背景（鼠标交互效果）
- 头像（圆形，带发光边框）
- 主标题：姓名 + 职位标签
- 副标题：个人标语
- CTA 按钮："了解更多" + "联系我"

**动画效果**：
- 页面加载时元素依次淡入（staggered animation）
- 头像轻微悬浮动画
- 粒子随鼠标移动产生涟漪效果

### 4.2 About Section（关于我）
**内容**：
- 个人照片（可选）
- 个人简介（200字左右）
- 技能标签（技术栈）
- 教育背景/工作经历时间线

**布局**：
- 双栏布局：文字在左，照片在右
- 技能以标签云形式展示
- 时间线使用垂直布局

### 4.3 Projects Section（作品集）
**内容**：
- 4-6 个项目卡片
- 每个项目包含：封面图、项目名称、描述、技术标签、链接

**布局**：
- 网格布局（2列）
- 卡片悬停时上浮并显示更多信息
- 玻璃态卡片设计

### 4.4 Blog Section（博客）
**内容**：
- 最新 3-4 篇文章预览
- 每篇包含：标题、摘要、日期、阅读时间、分类标签

**布局**：
- 卡片列表布局
- 点击可跳转（预留扩展性）
- 简洁的文章预览设计

### 4.5 Contact Section（联系方式）
**内容**：
- 社交媒体链接（GitHub, LinkedIn, Email 等）
- 简短的联系邀请语
- 可选的联系表单

**布局**：
- 居中布局
- 大号图标按钮
- 优雅的悬停效果

## 五、动画与交互规范

### 5.1 全局动画
- **滚动触发动画**：元素进入视口时淡入上移
- **过渡时间**：`300-500ms`
- **缓动函数**：`cubic-bezier(0.4, 0, 0.2, 1)`

### 5.2 交互反馈
- **按钮悬停**：发光效果 + 轻微缩放（scale: 1.02）
- **卡片悬停**：上浮 8px + 边框高亮
- **链接悬停**：下划线动画 + 颜色渐变

### 5.3 背景粒子效果
- **粒子数量**：100-150 个
- **粒子大小**：2-6px 随机
- **运动**：缓慢漂浮 + 鼠标交互
- **颜色**：渐变色调（紫、青、蓝）
- **连线**：距离较近的粒子之间连线

## 七、假设与决策

### 7.1 设计决策
- 采用**单页面设计**，所有内容在一个页面内展示，提升浏览体验
- 使用**深色主题**，更符合现代炫酷风格
- **暂不使用后端**，所有内容为静态展示，便于部署和维护
- **Canvas 粒子背景**作为视觉亮点，而非纯 CSS 效果

### 7.2 内容假设
- 个人网站将展示**虚构但真实感**的人物形象（前端开发者）
- 包含**4 个项目**和**4 篇博客文章**的示例内容
- 提供**社交媒体链接**（GitHub, LinkedIn, Twitter, Email）

### 7.3 技术决策
- 使用 **React Hooks** 管理组件状态
- 采用 **CSS Modules** 或 **Tailwind CSS** 处理样式
- 所有动画优先使用 **CSS**，复杂动画使用 **Framer Motion**
- **性能优先**：粒子数量可配置，避免性能问题
